# fgis-utko-route-generator

Утилита для преобразования данных из Excel-файлов в структурированный JSON-формат, соответствующий схеме маршрутов объектов в системе учёта твёрдых коммунальных отходов (ФГИС УТКО).  
Скрипт автоматически обрабатывает таблицы с данными о населённых пунктах, объектах размещения/обработки/утилизации и параметрах движения, генерируя валидный JSON для интеграции с системами учёта и визуализации.

## Назначение

Проект предназначен для:
- Автоматизации подготовки данных для **ФГИС УТКО**.
- Преобразования **ручных Excel-выгрузок** в **стандартизированный JSON**.
- Упрощения загрузки маршрутов сбора ТКО в информационные системы.
- Поддержки многоуровневой структуры маршрутов: **1, 2 и 3 плечо** (до трёх объектов переработки/утилизации).

## Функции

1. Поддержка **многоуровневых маршрутов** (цепочка: населённый пункт → объект 1 → объект 2 → объект 3)  
2. Автоматическое определение типа объекта:
- `размещение` → `DisposalObject`
- `обработка` → `AssortmentObject`
- `обезвреживание` → `IncinerationObject`
- `утилизация` → `CompostingObject`
- `хранение` → `StorageObject`
- `перегрузка` → `TransshipmentObject`

3. Безопасные вычисления:
- Автоматическое деление `Distance / Speed = TravelTime` с защитой от деления на ноль.
- Обработка `NaN`, пустых и некорректных значений.

4. Гибкая обработка:
- Пропуск строк с ошибками (с логированием).
- Поддержка нескольких Excel-файлов в папке.
- Интерактивный выбор файла и имени выходного JSON.

## Как использовать

### 1. Установите зависимости:
```bash
pip install pandas openpyxl
```

> `openpyxl` нужен для чтения `.xlsx`, в другие файлы он автоматически не лезет.

### 2. Поместите Excel-файл в папку с скриптом
Файл должен соответствовать структуре УТКО (с данными по плечам, координатами, скоростями и т.д.).

### 3. Запустите скрипт:
```bash
python excel_to_json.py
```

### 4. Следуйте инструкциям:
- Выберите номер Excel-файла из списка.
- Укажите имя для JSON-файла (или нажмите Enter для автоматического имени).

### 5. Готово!
JSON будет сохранён в той же папке.

## Как работает

1. Скрипт читает Excel, пропуская первые 2 строки (заголовки).
2. Парсит данные по колонкам (жёсткое соответствие: G, H, I...).
3. Для каждого населённого пункта строит цепочку маршрутов:
   - Проверяет наличие данных по 2-му и 3-му плечу.
   - Вычисляет `TravelTime = Distance / Speed`.
   - Приводит типы данных к `float`, `str`, `int`.
4. Формирует вложенный JSON с правильной иерархией.
5. Сохраняет результат в файл.
